## 📌 About the Project

**QuizMaster** is an online quiz and examination platform designed to help students improve their knowledge, practice programming, and test their skills through interactive quizzes.

The platform aims to provide a simple, modern, and user-friendly experience with multiple subjects, question navigation, timers, scores, and result tracking.

## ✨ Features

- 🔐 User Registration and Login
- 🌐 Google Sign-In integration
- 📚 Multiple quiz subjects
- 💻 Programming quizzes: C, C++, Java, and Python
- 🧠 General Knowledge and Aptitude quizzes
- 🔄 English and Tamil question support
- ⏱️ Timed examinations
- 📝 Multiple-choice questions (MCQs)
- 📊 Automatic score calculation
- 🏆 Quiz results and performance tracking
- 👤 User profile management
- 🌙 Light Mode and Dark Mode
- 📱 Responsive design for mobile and desktop
- 🎨 Modern user interface with interactive animations

> Note: Features may be under development. Only features implemented and tested in the current source code should be considered available.

## 🎯 Project Objectives

- Make online learning interactive and enjoyable.
- Help students practise programming concepts.
- Improve logical thinking and problem-solving skills.
- Provide quizzes in English and Tamil.
- Make self-assessment easier for students.
- Create a clean and accessible user experience.
